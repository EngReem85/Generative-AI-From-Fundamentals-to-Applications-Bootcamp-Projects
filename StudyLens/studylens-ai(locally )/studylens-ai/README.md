# StudyLens AI (نسخة محلية بالكامل)

مشروع كامل (backend حقيقي + frontend) يحوّل أي صورة لصفحة تعليمية — كتاب، محاضرة،
رسم بياني، معادلة، جدول، أو مخطط — إلى: **ملخص، مفاهيم أساسية، مصطلحات مهمة، شرح،
وأسئلة مراجعة**، مع إمكانية سؤال المتابعة والاختبار الذاتي.

هذه النسخة تعمل **100% محلياً على جهازك** عبر [Ollama](https://ollama.com) —
بدون إنترنت (بعد تحميل الموديل مرة واحدة)، بدون أي مفتاح API، وبدون أي حد استخدام.
الصور لا تغادر جهازك أبداً.

## هيكل المشروع

```
studylens-ai/
├── backend/
│   ├── app.py            ← خادم Flask: يقدّم الواجهة + يتصل بـ Ollama محلياً
│   ├── requirements.txt  ← مكتبات بايثون المطلوبة
│   └── .env.example      ← انسخه إلى .env (اختياري، القيم الافتراضية تعمل مباشرة)
├── frontend/
│   ├── index.html
│   ├── style.css
│   └── app.js
└── README.md
```

## 1. ثبّت Ollama

حمّل وثبّت Ollama من: https://ollama.com/download (يدعم Windows وmacOS وLinux)

بعد التثبيت، تأكد أنه يعمل (عادة يعمل تلقائياً في الخلفية). للتأكد يدوياً:

```bash
ollama serve
```

## 2. نزّل موديل الرؤية

هذا هو "عقل" التطبيق — الموديل الذي يقرأ الصور ويفهمها. الافتراضي المقترح:

```bash
ollama pull qwen2.5vl:7b
```

> التحميل عدة غيغابايتات وقد يأخذ وقتاً حسب سرعة إنترنتك — لكنها المرة الوحيدة.

### أي موديل أختار؟

| جهازك | الموديل المقترح | ملاحظات |
|---|---|---|
| رام محدودة / بدون كرت شاشة قوي | `moondream2` | الأسرع والأخف (~2GB)، لكن دقته أقل في قراءة النصوص الكثيفة والجداول |
| جهاز متوسط (8-16GB رام/VRAM) | `qwen2.5vl:7b` **(الافتراضي)** | أفضل توازن لقراءة المستندات، الجداول، والرسوم البيانية |
| جهاز قوي (GPU جيد أو Mac بذاكرة موحّدة كبيرة) | `llama3.2-vision:11b` أو `qwen2.5vl:32b` | جودة أعلى بشكل ملحوظ |

لتغيير الموديل: نزّله بـ `ollama pull <اسم الموديل>`، ثم عدّل `OLLAMA_MODEL` في
`backend/.env` (انسخ `.env.example` إلى `.env` أولاً إن لم يكن موجوداً).

## 3. ثبّت مكتبات بايثون وشغّل الخادم

يتطلب Python 3.9 فأعلى.

```bash
cd backend
pip install -r requirements.txt
python app.py
```

سترى في الطرفية:

```
✅ تم العثور على Ollama يعمل على http://localhost:11434
🚀 StudyLens AI يعمل الآن على: http://localhost:5000
```

افتح `http://localhost:5000` في متصفحك وابدأ.

## ملاحظة مهمة عن السرعة والدقة

النموذج المحلي **مجاني وخاص بالكامل**، لكن مقارنة بالخدمات السحابية:

- **الاستجابة أبطأ**، خصوصاً أول تحليل على جهاز بدون كرت شاشة مخصص (قد يأخذ من
  عشرات الثواني إلى دقيقة أو أكثر). هذا طبيعي تماماً.
- **الدقة في القراءة الكثيفة للنصوص/الجداول المعقدة قد تكون أقل** من نماذج سحابية
  كبيرة. موديل `qwen2.5vl` مختار خصيصاً لأنه الأفضل محلياً في هذا النوع من المهام.
- إذا كانت النتائج غير دقيقة، جرّب صورة أوضح وأقرب، أو انتقل لموديل أكبر إن كان
  جهازك يسمح.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| "تعذّر الاتصال بـ Ollama على جهازك" | تأكد أن Ollama يعمل (`ollama serve` أو افتح تطبيق Ollama من قائمة البرامج). |
| "الموديل غير محمّل على جهازك" | نفّذ `ollama pull qwen2.5vl:7b` (أو اسم الموديل الذي وضعته في `.env`). |
| التحليل بطيء جداً أو يتوقف | جرّب موديلاً أصغر مثل `moondream2`، أو ارفع `OLLAMA_TIMEOUT_SECONDS` في `.env`. |
| نفاد الذاكرة (Out of memory) | جهازك لا يتحمل حجم الموديل الحالي — انتقل لموديل أصغر مثل `moondream2`. |
| نتائج JSON غير دقيقة أحياناً | طبيعي مع النماذج الصغيرة أحياناً — أعد رفع الصورة أو جرّب موديلاً أكبر. |

## أفكار للتوسعة لاحقاً

- حفظ سجل المحادثات محلياً (SQLite) لكل صورة.
- دعم رفع عدة صور لنفس الجلسة (فصل كامل من محاضرة).
- تصدير التحليل كملف PDF أو ملاحظات Markdown.
- زر لتبديل الموديل من داخل الواجهة مباشرة بدون تعديل `.env`.
