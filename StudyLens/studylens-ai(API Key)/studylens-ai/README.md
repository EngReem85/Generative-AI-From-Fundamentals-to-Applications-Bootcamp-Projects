# StudyLens AI

مشروع كامل (backend حقيقي + frontend) يحوّل أي صورة لصفحة تعليمية — كتاب، محاضرة،
رسم بياني، معادلة، جدول، أو مخطط — إلى: **ملخص، مفاهيم أساسية، مصطلحات مهمة، شرح،
وأسئلة مراجعة**، مع إمكانية سؤال المتابعة والاختبار الذاتي.

يعمل بالكامل على مفتاح **Gemini API المجاني** من Google (بدون أي اشتراك مدفوع).
مفتاح الـ API يبقى على جهازك في ملف `.env` ولا يظهر أبداً في المتصفح — الـ backend
هو من يتصل بـ Gemini نيابة عن الواجهة الأمامية.

## هيكل المشروع

```
studylens-ai/
├── backend/
│   ├── app.py            ← خادم Flask: يقدّم الواجهة + يتصل بـ Gemini
│   ├── requirements.txt  ← مكتبات بايثون المطلوبة
│   └── .env.example      ← انسخه إلى .env وضع مفتاحك فيه
├── frontend/
│   ├── index.html
│   ├── style.css
│   └── app.js
└── README.md
```

## 1. احصل على مفتاح Gemini المجاني (دقيقتان)

1. افتح: https://aistudio.google.com/apikey
2. سجّل الدخول بحساب Google.
3. اضغط "Create API key" — لا حاجة لبطاقة ائتمان.
4. انسخ المفتاح.

> ملاحظة: الفئة المجانية لها حد أقصى للطلبات في الدقيقة/اليوم (يتغيّر من وقت لآخر
> حسب سياسة Google). إذا ظهرت رسالة "تم تجاوز الحد المجاني" داخل التطبيق، انتظر
> دقيقة وحاول مرة أخرى.

## 2. جهّز المشروع

```bash
cd studylens-ai/backend
cp .env.example .env
```

افتح ملف `.env` بأي محرر نصوص وضع مفتاحك مكان `ضع_مفتاحك_هنا`:

```
GEMINI_API_KEY=AIzaSy...
```

## 3. ثبّت المكتبات وشغّل الخادم

يتطلب Python 3.9 فأعلى.

```bash
pip install -r requirements.txt
python app.py
```

سترى في الطرفية:

```
🚀 StudyLens AI يعمل الآن على: http://localhost:5000
```

افتح هذا الرابط في متصفحك وابدأ.

## استكشاف الأخطاء

| المشكلة | الحل |
|---|---|
| "GEMINI_API_KEY غير موجود" | تأكد أنك أنشأت `.env` داخل مجلد `backend/` (وليس فقط `.env.example`) وأعد تشغيل `python app.py`. |
| "مفتاح Gemini API غير صالح" | تأكد من نسخ المفتاح كاملاً بدون مسافات زائدة. |
| "تم تجاوز الحد المجاني" | انتظر دقيقة، الفئة المجانية محدودة الطلبات بالدقيقة. |
| خطأ متعلق باسم الموديل | الموديلات المجانية عند Google تتغيّر بمرور الوقت. راجع القائمة الحالية على https://ai.google.dev/gemini-api/docs/models وغيّر قيمة `GEMINI_MODEL` في `.env`. |

## أفكار للتوسعة لاحقاً

- حفظ سجل المحادثات محلياً (SQLite) لكل صورة.
- دعم رفع عدة صور لنفس الجلسة (فصل كامل من محاضرة).
- تصدير التحليل كملف PDF أو ملاحظات Markdown.
- تبديل النموذج تلقائياً إلى موديل مجاني بديل عند تجاوز الحد.
